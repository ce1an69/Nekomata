## [0.1.0] - 2026-06-04

### 新增

- 78 张像素风猫咪塔罗牌，包含正位/逆位释义
- 5 种牌阵布局（单牌、过去-现在-未来、身-心-灵、五牌十字、处境-行动-结果）
- 通过 OpenAI 兼容 API 进行 AI 解读（SSE 流式传输）
- 三种运行模式：TUI（默认）、CLI、Desktop（PyWebView）
- 双语支持（英文 / 中文）
- Catppuccin Mocha 主题
- 牌组浏览器，支持按花色筛选
- 图片导出（Catppuccin 主题 PNG）
- 跨平台剪贴板支持
- macOS（.dmg）和 Windows（.exe）桌面端构建
